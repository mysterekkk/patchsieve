# Code of Conduct

We follow the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

- Be respectful and constructive. Critique code and ideas, not people.
- No harassment, discrimination, personal attacks or unwelcome sexual attention.
- Assume good faith; explain false positives with a reproducible example.

Maintainers may remove comments, commits or issues that violate this code and may ban repeat offenders. Report concerns through a private GitHub security advisory contact on this repository or by contacting the maintainers via their GitHub profile.
